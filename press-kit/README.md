# The Solid Chain · Press Kit

Herramientas de desarrollo para blockchain: **reCode** (orquestación de agentes
de IA para desarrollo), **reDeploy** (despliegue visual de smart contracts) y
**reDeFi** (SDK de DeFi). Web: https://thesolidchain.com

## Contenido
- `logos/` — marca corporativa en SVG (máster y corte pequeño) y PNG 1024
  (positivo carbón / negativo crema, fondo transparente), más el avatar para
  redes/GitHub (`tsc-org-avatar-1024.png`, crema sobre carbón); `logos/products/`
  con los tres badges de producto (SVG + PNG 1024) y la lámina de familia.
- `favicon/` — favicon.ico multirresolución, tsc-favicon.svg (vectorial) y PNG 16/24/32.
- `ascii/` — la marca en caracteres (one-liners y 3-liners) para contextos
  de texto: `=[s=c]=`

## Tipografía
Space Grotesk (titulares y texto) · monoespaciada del sistema (datos y rotulación).

## Reglas rápidas
- Zona de respeto: un grosor de marco por cada lado. No deformar, no rotar,
  no recolorear parcialmente, no cerrar las aperturas del marco.
- Máster ≥ 48 px · corte pequeño 24-48 px · favicon tipográfico ≤ 32 px.
- Los badges de producto están diseñados para fondos oscuros.

Guía completa: `brand-book.html` en el repositorio de la marca.
